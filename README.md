# Selenium Java QA Automation

## Overview
This project demonstrates web application test automation using Selenium WebDriver and Java.

## Testing Technologies
- Selenium WebDriver
- Java
- TestNG
- Cucumber
- Maven
- Git & GitHub

## Testing Coverage
- Functional Testing
- Regression Testing
- Smoke Testing
- End-to-End Testing
- UI Automation Testing

## Project Structure
- Test cases and test scenarios
- Selenium automation scripts
- TestNG test execution
- Cucumber feature files
- Test execution reports

## Objective
To demonstrate practical QA automation skills including test design, automation scripting, test execution, defect identification and reporting.
